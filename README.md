# Hi, I'm Vic

Exploring AI for cyclic peptide research, topology-aware evaluation, and reproducible workflows.

正在探索 AI 在环肽研究中的应用，关注拓扑感知的评估与可复现的工作流程。

## Building / 正在做

[cyclic-peptide-audit](https://github.com/Vic00012385/cyclic-peptide-audit) — in development. A small Python CLI for auditing candidate tables, comparing closure status before and after relaxation, and reporting transparent screening counts.

一个轻量 Python 命令行工具：检查候选表格、比较松弛前后的闭环状态，并生成筛选统计报告。

The project uses synthetic demo data. It is an evaluation utility, not a peptide generation or binding prediction model.

项目使用合成演示数据；它是评估辅助工具，不是肽生成模型或结合力预测模型。
